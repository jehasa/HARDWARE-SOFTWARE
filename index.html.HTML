¿Sabias que...?

El término "Bug" (bicho/error) en informatica se usa porque en 1947, los ingenieros de la computadora Harvard Mark II encontraron una polilla real atrapada en uno de los reles magneticos, lo que hacia que el sistema fallara. Al removerla, pegaron el insecto en la bitacora del laboratorio anotando que fue el primer caso real de un "bicho" causando un problema de hardware.

1. Hardware: El cuerpo del sistema

Es el conjunto de componentes fisicos que puedes tocar. Se divide principalmente en:

CPU

La Unidad Central de Procesamiento es el "cerebro" que ejecuta todas las instrucciones.

Memoria RAM

El espacio de trabajo temporal donde se guardan los datos que se estan usando en el momento.

Almacenamiento

Discos duros (HDD) o unidades de estado solido (SSD) donde se guarda la informacion permanentemente.

Placa Base

La Motherboard es la tarjeta de circuitos principal que conecta todos los componentes anteriores.

2. Software: La mente del sistema

Es el conjunto de programas, instrucciones y reglas informaticas que permiten ejecutar tareas. Es intangible.

Software de Sistema

Permite que el hardware funcione y sirve de interfaz.
Ejemplos: Windows, macOS, Linux, Android y drivers.

Software de Aplicación

Programas diseñados para realizar tareas especificas.
Ejemplos: Chrome, Word, Photoshop o videojuegos.

Software de Programación

Herramientas que usan los desarrolladores para crear otros programas.
Ejemplos: VS Code, compiladores e intérpretes.

¿Quieres saber mas? Lenguajes de Programación y Algoritmos (Haz clic aqui)

Para que el software exista, se necesita traducir la logica humana a un formato estructurado que entiendan los microchips. Aqui profundizamos en como se logra:

Estructura de un Algoritmo

Un algoritmo es una receta exacta. Para ser util en programación, todo buen algoritmo debe cumplir obligatoriamente tres partes estructurales:

  • Entrada (Input): Los datos iniciales que se reciben para trabajar.
  • Proceso: Las operaciones matematicas o logicas que se le aplican a esos datos.
  • Salida (Output): El resultado final arrojado en pantalla o dispositivo.

Tipos de Lenguajes

No todos los lenguajes hablan directamente con los circuitos. Se dividen segun su nivel de abstraccion:

  • Bajo Nivel (Codigo Maquina / Binario): Ceros y unos ($0$ y $1$) que representan impulsos electricos. Lo entiende el hardware puro.
  • Alto Nivel: Usan palabras e instrucciones similares al inglés humano (como Python, JavaScript o C++), siendo infinitamente mas sencillos de escribir y entender.

La Programación en la Automatización

Cuando los lenguajes de alto nivel se combinan con microcontroladores (como las placas electrónicas de desarrollo), el software adquiere la capacidad de controlar el hardware en el mundo fisico de forma automatica. Mediante lecturas de sensores de entrada, el codigo toma decisiones logicas en tiempo real para activar actuadores fisicos (como motores, reles, sistemas de riego o luces LED), cerrando el ciclo perfecto entre la logica abstracta y la accion material.

5. Definición e Importancia

Definición Resumida

Una computadora es la suma de sus dos partes vitales:

Computadora = Hardware (Maquina) + Software (Instrucciones)

Sin hardware, el software no tiene donde ejecutarse; sin software, el hardware es solo un objeto inerte.

Importancia

Automatización

Permiten realizar tareas sumamente complejas en milisegundos.

Conectividad

Facilitan la comunicación global y el acceso instantaneo a la informacion.

Productividad

Son herramientas esenciales en la educacion, la medicina, el diseno y la ingenieria de desarrollo.
